# أصوات تنبيهات المواسم — `public/audio/seasons/`

الفهرس البرمجي: `SEASON_SOUNDS` و`SEASON_SOUND_BY_REMINDER` في
`src/lib/seasons/sounds.ts`. حزمة مستقلة بقنوات إشعار ببادئتها الخاصة
(`manar_season_<مورد>`)، فلا تختلط بنداءات الأذكار ولا بتنبيهات ما قبل الصلاة.

## الملفات

| الملف                       | المعرّف          | النص                                     |
| --------------------------- | ---------------- | ---------------------------------------- |
| `season-general.mp3`        | `general`        | الصوت الاحتياطي العام (الافتراضي)        |
| `season-new.mp3`            | `new`            | موسم جديد في منار                        |
| `season-friday-eve.mp3`     | `friday-eve`     | غدًا الجمعة، فأكثر من الصلاة على النبي ﷺ |
| `season-friday-day.mp3`     | `friday-day`     | جمعة مباركة، لا تنسَ سورة الكهف          |
| `season-fast-eve.mp3`       | `fast-eve`       | غدًا يوم يُستحبّ صيامه                   |
| `season-white-days-eve.mp3` | `white-days-eve` | غدًا أول الأيام البيض                    |

## توزيع الأصوات

| التنبيه                                                                          | الصوت                       |
| -------------------------------------------------------------------------------- | --------------------------- |
| الجمعة: ليلتها / صباحها                                                          | `friday-eve` / `friday-day` |
| ليلة الاثنين والخميس                                                             | `fast-eve`                  |
| ليلة الأيام البيض                                                                | `white-days-eve`            |
| اقتراب رمضان (أسبوع، ٣ أيام، ليلته)، ليلة عشر ذي الحجة وأول أيامها، أول المحرّم  | `new`                       |
| العشر الأواخر، عيد الفطر، الست من شوال، ليلة عرفة، ليلة الأضحى، تاسوعاء وعاشوراء | `general`                   |
| أي تنبيه يُضاف لاحقًا بلا صوت محدّد                                              | `general`                   |

اختبار `tests/unit/season-sounds.test.ts` يُفشل البناء إن أُضيف تنبيه موسمي دون
أن يُنصّ على صوته، أو بقي ملف صوت غير مستعمل.

## الحجم والجودة

- الملفات الأصلية مشحونة **كما سُجّلت بالبت** (MP3 أحادي 44.1 ك.هـ، 128 ك.ب/ث)
  بلا إعادة ترميز؛ حُذفت البيانات الوصفية فقط. المجموع نحو ٤١٠ ك.ب.
- النسخ المخفّضة لدرجات مستوى الصوت (٢٠/٤٠/٦٠/٨٠٪) في `assets/audio-levels/`
  تُولَّد بـ`node scripts/build-volume-levels.mjs` بترميز VBR (‏LAME ‎-V5) المناسب
  للكلام، بدل ٩٦ ك ثابتة، فتصغر نحو ١٥–٢٠٪ بجودة الكلام نفسها.
- تسجيل «غدًا يوم يُستحبّ صيامه» وصل بنسختين؛ اعتُمدت الأقصر المتصلة بلا وقفة.

**الحقوق: موثّقة (VERIFIED).** سجّلها صاحب المشروع بصوته (٢٦ سبتمبر ٢٠٢٦)، وهي
مدرجة في `licenses.json` تحت `verified_season_files` ومشمولة بـ`owner_recordings`.
