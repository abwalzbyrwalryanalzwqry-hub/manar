# أصوات تذكيرات الأذكار والوِرد — `public/audio/reminders/`

الفهرس البرمجي: `REMINDER_TONES` في `src/lib/daily-reminders.ts`. كل صوت يحمل
`kind` فتعرضه الواجهة في إحدى مجموعتين:

## النغمات (`kind: "tone"`) — مولَّدة داخل منار

| الملف                  | الاسم في الواجهة |
| ---------------------- | ---------------- |
| `azkar-morning.mp3`    | إشراق            |
| `azkar-evening.mp3`    | أصيل             |
| `wird.mp3`             | تأمّل            |
| `reminder-bell.mp3`    | جرس              |
| `reminder-default.mp3` | هادئ             |
| `reminder-chime.mp3`   | نقرة             |

مولَّدة بـ`scripts/build-tones.py` (`npm run audio:tones`)، فلا حقوق فيها لطرف آخر.

## النداءات الصوتية (`kind: "voice"`) — نداء واحد لكل موضوع

| الملف                  | الاسم في الواجهة         | الموضوع (`topic`) | يظهر في                                  |
| ---------------------- | ------------------------ | ----------------- | ---------------------------------------- |
| `azkar-morning-03.mp3` | حان وقت أذكار الصباح     | `morning`         | أذكار الصباح                             |
| `azkar-evening-02.mp3` | حان وقت أذكار المساء     | `evening`         | أذكار المساء                             |
| `azkar-sleep-02.mp3`   | حان وقت أذكار النوم      | `sleep`           | أذكار النوم                              |
| `azkar-wake-01.mp3`    | أذكار الاستيقاظ من النوم | `wake`            | «تذكير» المضاف                           |
| `wird-daily-01.mp3`    | لا تنسَ وِردك اليومي     | `wird`            | الوِرد، وِرد قبل النوم، الضحى، القرآن    |
| `wird-quran-01.mp3`    | لا تنسَ وِردك من القرآن  | `quran`           | الوِرد، وِرد قبل النوم، القرآن           |
| `azkar-general-01.mp3` | لا تنسَ الأذكار          | `general`         | الصباح، المساء، النوم، بعد الصلاة، الضحى |

كل تذكير يعرض في تبويب «نداءات صوتية» ما يناسب موضوعه فقط (`toneOptionsFor`)،
والمقترح أولاً؛ و«تذكير» العام المضاف يعرضها كلها. النغمات عامة فتظهر في كل تذكير.

حُذفت خمسة نداءات مكرّرة الموضوع (`azkar-morning-01`، `azkar-morning-02`،
`azkar-evening-01`، `azkar-sleep-01`، `azkar-general-02`) مع نسخها المخفّضة في
`assets/audio-levels/`. من اختار أحدها يُنقل تلقائيًا إلى نداء موضوعه الباقي
(`REMOVED_TONE_MIGRATION`).

**الحقوق: غير موثّقة بعد (PENDING).** بخلاف تسجيلات الأذان والإقامة
(`licenses.json`, `rights_status: VERIFIED`)، لا يوجد في المستودع توثيق لمصدر هذه
النداءات ولا لحقّ نشرها. لذلك صُحّحت عبارة الواجهة التي كانت تقول إن «كل النغمات
مُركَّبة داخل التطبيق فلا تحمل أي حقوق لطرف آخر».

المطلوب من صاحب المشروع قبل النشر: توثيق المصدر وحقّ الاستعمال لكل ملف، ثم
إضافتها إلى `licenses.json` تحت `verified_reminder_files` كما وُثّقت أصوات الإقامة.
