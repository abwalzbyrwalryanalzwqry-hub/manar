# منظومة الأذان والإقامة والتنبيهات — أندرويد

## التدفّق لكل صلاة

```
(الأذان الأول للفجر — اختياري)
دخول الوقت ── الأذان (صوت)        أو  إشعار دخول الوقت (نصّ) إن كان الأذان معطّلًا
      ↓        + إشعار يبقى بعد انتهاء الأذان (إن كان «إشعار دخول الوقت» مفعّلًا)
تنبيه قبل الإقامة (نصّ، اختياري: ٢/٣/٥/١٠ دقائق)
      ↓
الإقامة (صوت من مكتبة الإقامة وحدها، أو إشعار صامت إن أُطفئ صوت الإقامة)
```

كل مرحلة بمفتاح مستقل: تعطيل الأذان لا يعطّل الإقامة، وتعطيل الإقامة لا يعطّل
الأذان. التنبيهات قبل الصلاة تبقى عبر `LocalNotifications` كما كانت.

## من يبني الجدول ومن ينفّذه

| الطبقة                    | الملف                             | الدور                                                        |
| ------------------------- | --------------------------------- | ------------------------------------------------------------ |
| بناء الجدول (دالّة نقيّة) | `src/lib/prayer-schedule.ts`      | ٣٠ يوماً: الأذان والإقامة والتنبيه قبل الصلاة، بمفاتيح فريدة |
| التسليم                   | `src/lib/native-notifications.ts` | `syncNativePrayerSchedule` → `ManarAdhan.schedule`           |
| الضبط                     | `AdhanScheduler.java`             | `setExactAndAllowWhileIdle` + حفظ القائمة + منع التكرار      |
| الإطلاق                   | `AdhanAlarmReceiver.java`         | فحص «أُطلق من قبل؟» ثم إشعار نصّي أو تشغيل                   |
| الصوت                     | `AdhanService.java`               | خدمة أمامية mediaPlayback، مشغّل واحد، تركيز الصوت           |
| النصوص                    | `ManarNotices.java`               | إشعارات بلا صوت على قناتي الأذان والإقامة                    |
| إعادة الضبط               | `BootReceiver.java`               | الإقلاع، التحديث، تغيير الوقت/المنطقة                        |

داخل تطبيق أندرويد لا يُطلق الويب أيّ أذان أو إقامة أو تنبيه (لا مؤقّت JavaScript):
الطبقة الأصلية وحدها تُطلق، فلا يتكرّر شيء والتطبيق مفتوح.

## منع التكرار

- مفتاح لكل حدث: `fajr_adhan_2026_09_23`، `fajr_iqamah_2026_09_23`،
  `asr_iqamah_reminder_2026_09_23`… ومعرّف رقمي مشتقّ من التاريخ لا من ترتيب اليوم.
- `replaceAll` يُلغي كل ما سبق ثم يضبط — استبدال لا إضافة.
- `markFired` يحفظ آخر ٩٦ مفتاحًا أُطلق؛ لو أعاد النظام حدثًا يُتجاهل.
- مشغّل واحد: بدء صوت جديد يوقف السابق أولًا.

## إعادة الجدولة التلقائية

عند: فتح التطبيق/العودة إليه، تغيير المدينة أو الموقع أو طريقة الحساب أو المذهب
أو فروق الدقائق، تغيير أي إعداد أذان/إقامة/تنبيه، تغيّر اليوم أو المنطقة الزمنية
والتطبيق مفتوح، وبعد إعادة تشغيل الجهاز أو تحديث التطبيق أو تغيير الساعة
(`BootReceiver` يعيد ضبط القائمة المحفوظة دون فتح التطبيق).

## حدود معروفة

- الأذان والإقامة والتنبيه قبل الصلاة و«تذكير الفجر»: ٣٠ يوماً في `AdhanScheduler`
  (نافذة ٤٨ ساعة مضبوطة). الأذكار والمواسم والجمعة: ١٤ يوماً في LocalNotifications
  بحدٍّ أعلى ٢٤٠. سكينة: ٧ أيام. تنبيه «افتح منار» يسبق نهاية أقصرها بيومين.
- بعد تغيّر المنطقة الزمنية فعلاً (سفر) يصل «تغيّرت منطقتك الزمنية — افتح منار».
- بعض الشركات (شاومي، هواوي، أوبو…) تقتل التطبيقات بقوة؛ منار يطلب استثناء
  البطارية مرة واحدة، والباقي بيد المستخدم.
- «إيقاف إجباري» من الإعدادات يُلغي منبّهات أي تطبيق حتى يُفتح من جديد — سلوك أندرويد.
- التثويب بعد أذان الفجر يُسلسَل أصلياً في `AdhanService` بعد الأذان المجدول (حقل `follow`)، والكتم والإيقاف يشملانه.
