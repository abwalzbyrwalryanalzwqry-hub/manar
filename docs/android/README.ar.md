# منار — دليل بناء تطبيق أندرويد (محدَّث وموثَّق بتنفيذ فعلي)

هذا الملف هو المرجع الحالي. الملف الإنجليزي `README.md` يوثّق التخطيط الأصلي قبل
تنفيذ البناء، وبعض فقراته صارت قديمة (خصوصًا قوله إنه لا يمكن البناء هنا وإنه لا
توجد حزمة جاهزة).

آخر تحديث: بناء ناجح وموقَّع من الفرع `android-release-prep`.

## ٢. خطوات البناء

```bash
npm ci
npm run typecheck            # tsc --noEmit
npm run build:android        # vite build + تهيئة مجلد الويب + نسخ الأصوات إلى res/raw + cap sync
cd android
./gradlew assembleRelease    # APK موقَّع
./gradlew bundleRelease      # AAB لمتجر Play
```

المخرجات:

- `android/app/build/outputs/apk/release/app-release.apk` — **٤٠ ميغابايت**
- `android/app/build/outputs/bundle/release/app-release.aab` — **٣٥ ميغابايت**

- كلمة المرور في `android/keystore.properties` — والملفان **مستثنيان من Git**.
- الشهادة: `CN=Manar, OU=Manar App, O=Manar, L=Sanaa, C=YE`
- بصمة SHA-256: `563c08a1c2fec0d9558272548ad2f45fe29544240f925b53acb0f151c22d78ec`
- بصمة SHA-1: `ba44800253b496dbf88256770b34367769ca097d`

## ٥. مشكلتان حقيقيتان تم إصلاحهما في هذه الجولة

1. **`shrinkResources` كان يحذف كل ملفات الأذان.** الملفات في `res/raw` تُطلب وقت
   التشغيل عبر `getIdentifier()` فلا يراها المُصغِّر مستخدَمة، فحذف الـ ٢٠ ملفًا
   كلها من الحزمة (كان الأذان سيرنّ بلا صوت). الحل: `android/app/src/main/res/raw/keep.xml`
   مع `tools:keep="@raw/*"`. التحقق: `aapt2 dump resources` يُظهر `type raw entryCount=21`.
2. **مسارات صوت معطّلة.** كانت متغيّرات الأذان/الإقامة/التنبيه تشير إلى
   `/audio/adhan/*.mp3` و`/audio/iqama/*.mp3` و`/audio/reminders/*.mp3` وهي مجلدات
   فارغة (README فقط)، فيظهر خطأ «ملف الصوت غير متوفر». الحل: توسيع
   `LEGACY_VARIANT_MIGRATION` لتغطية كل المؤذنين × كل الأنماط + الفجر + الإقامة +
   التنبيه، وربطها بملفات موجودة فعلًا في `public/audio/library`، وإرجاع `null`
   (صامت بلا خطأ) إذا لم يوجد ملف.

## ٦. تنبيهات مهمة قبل النشر

- حقوق تسجيلات الأذان `rightsStatus: "UNVERIFIED"` في `src/lib/adhan-library-assets.ts` —
  غير مُخلَّصة للنشر التجاري. راجعها قبل الرفع إلى Play.
- أسماء المؤذنين في `RECITER_INFO` لا تطابق دائمًا التسجيل الفعلي المربوط
  (مثال: النمط «مصري» مربوط بتسجيل عمر هاشم). تحتاج تسجيلات مطابقة لكل منطقة.
- ملف `.env` سابق يحتوي مفاتيح Supabase ما زال في تاريخ Git → **دوّر المفاتيح**.
- صوت تلاوات القرآن يعمل داخل التطبيق فقط؛ الخدمة الأصلية للتشغيل في الخلفية
  مخصّصة للأذان.

## ٧. قائمة اختبار على الجهاز (لا يمكن التحقق منها في بيئة البناء)

1. إشعار مجدول والتطبيق مغلق تمامًا.
2. إعادة الجدولة بعد إعادة تشغيل الجهاز.
3. صوت الأذان كاملًا + زر «إيقاف الأذان» من الإشعار.
4. التشغيل في الخلفية وأزرار شاشة القفل.
5. سلوك زر الرجوع بين التبويبات.
6. اتجاه RTL ورسم خط المصحف على أحجام شاشات مختلفة.
7. وضع Doze / تحسين البطارية وتأثيره على الدقة.
8. أذونات الموقع وحساب المواقيت بدون إنترنت.
9. بث تلاوة ثم تنزيلها والاستماع بدون إنترنت.
10. مشاركة بطاقة آية كصورة (Capacitor Share).
