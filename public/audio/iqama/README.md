# Iqama Audio Assets

Place real Iqama audio files here. Supported formats: MP3, WAV, OGG.

## Required filenames

- `iqama-full.mp3` — إقامة كاملة
- `iqama-qad.mp3` — قد قامت الصلاة
- `iqama-short.mp3` — تنبيه قصير
- `iqama-masjid.mp3` — على طريقة المساجد

Served from `/audio/iqama/<filename>`. `silent` plays no audio.
